# 길을 맞춰보는 과정

스탠리파크를 자전거로 돌다 길을 잃은 세 지점에서, 실제 시간과 느낀 시간을 비교하는 정보디자인 작업.

구성: 도입(문장 + 전체 지도 / 펜툴 온보딩 3화면 / 읽는 법) → 지점 01·02·03 (각각 지도: 그때의 안내 화살표 → 체감: 핸들을 맞추면 바퀴가 곡선을 굴러감 → 해결: 펜툴 동작 01 점 추가 / 02 점 옮기기 / 03 정렬, 끝나면 곡선이 펴지고 카드, 자전거 출발) → 정리(비교 곡선 + 표 / 깨달음)

## 파일

| 파일 | 내용 |
|---|---|
| `data.js` | ★ 모든 문장과 세 지점 데이터. 보통 이것만 고치면 됩니다 |
| `photos/` | 지도 위 사진 프레임 사진 `p01.jpg`~`p08.jpg` |
| `style.css` | 색과 글꼴. 색은 맨 위 `:root` |
| `main.js` | 지도, 체감 곡선과 핸들, 비교 화면 |
| `index.html` | 뼈대 |
| `reference/` | 시각 레퍼런스 (사이트에서는 쓰지 않음) |
| `_old/` | 이전 버전 보관 |

## data.js에서 고칠 것

- `actual` 실제 시간(분) → 빨간 직선 길이. 세 지점 모두 같은 축척입니다.
- `felt` 체감 시간(분) → 곡선 길이. 화면 높이를 넘을 만큼 길면 곡선이 고리처럼 꼬입니다. 바퀴가 굴러가는 시간도 체감에 비례 (가장 긴 지점 6초).
- `estimated: true` → 화면에 작게 "추정" 표시. 확인되면 `false`로 바꾸세요.
- `guide` 그때의 안내 → 지도 위 화살표. `label`(화살표 끝 말), `to`(가리키는 곳, 지도 좌표) 또는 `along`(실제 길을 따라 겹침), `dashed`(점선). `source: null`이면 화살표 없음.
- `fix` 다시 이어준 것 → 해결 화면: 사람(`who`), 펜툴 동작(`action`: add / move / align), 커서 옆 툴 이름(`tool`), 주석 카드(`text`, `line`)
- `table` 비교 화면 표 문구 (`guide`, `problem`, `human`, `humanSub`). 줄 이름은 `TEXT.table`
- `name`(지도·비교용 짧은 이름), `title`(지점 화면 위 이름), `space`(지도 화면 위 공간 한 줄)
- `at` 지도 위 위치 (경로 한 바퀴를 0~1로 본 값), `scene` 지도에 더 그릴 공간 (fork / forest / road)
- `TEXT.title` 표지의 큰 제목 (`<title>`·링크 미리보기는 `index.html`)
- `TEXT` 도입 문장, 읽는 법, 정의, 주제 문장
- `TEXT.hints` 처음 보는 사람용 동작 안내 문구 [마우스, 휴대폰]
- `TEXT.onboard` 표지 다음 펜툴 온보딩 3화면 문구 (`lines`, `sub`, 세 번째 화면의 `tools`)
- `PHOTOS` 첫 지도 위 사진 프레임: `time`(시각), `place`(장소), `file`(파일 이름), `at`(찍은 곳), `size`(large / small), `kind`(photo / phone / none), `hidden`(화면에서만 숨김). 누르면 크게 열리고, 위로 밀면 시각·장소·작은 지도가 나옵니다.
- `TRIP` 돌아오는 길 기록 (4:33 → 4:57, 약 24분)

## 미리 보기

`index.html`을 더블클릭하면 열립니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소에 올립니다.
2. **Settings → Pages**에서 Source를 `Deploy from a branch`, `main` / `(root)`로 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/`로 열립니다.

사진 파일 이름은 대소문자를 구분합니다 (`p01.JPG` ≠ `p01.jpg`).
