# 스탠리파크에서 길을 잃은 날

길을 잃은 동안, 나는 언제 가장 불안했을까?
공간·사람·휴대폰, 세 가지 정보의 관계를 따라가는 인터랙티브 사건 지도.

## 파일

| 파일 | 내용 | 직접 수정 |
|---|---|---|
| `data.js` | 모든 문장, 사건 11개, 불안 수치, 체감시간, 화살표 방향 | ★ 주로 여기만 |
| `map.js` | 지도 모양, 지명, 이동 경로 좌표 | 경로를 바꿀 때 |
| `style.css` | 색, 글꼴, 레이아웃 (세 정보 색은 맨 위 `:root`) | 색을 바꿀 때 |
| `main.js` | 화면 그리기, 스크롤 연동 | 보통은 필요 없음 |
| `index.html` | 뼈대 | 보통은 필요 없음 |

## 미리 보기

`index.html`을 더블클릭하면 브라우저에서 바로 열립니다. 서버가 필요 없습니다.

## 자주 고칠 것

- **불안 수치**: `data.js`의 각 사건 `anxiety: 0~10`. 현재 값은 임시값입니다.
- **체감시간**: `time: { actual: 7, felt: 30 }`. 없으면 `time: null`.
- **화살표 방향**: `dir`에 `"forward"`, `"back"`, `"left"`, `"right"`, `"stop"`, `"fading"`, `null` 중 하나를 넣습니다.
- **사건 위치**: `at` 값은 `map.js`의 `route` 안에 있는 `id`를 가리킵니다. 위치를 옮기려면 그 점의 `x`, `y`를 고치세요.

## GitHub Pages 배포

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다.
2. 저장소의 **Settings → Pages**로 갑니다.
3. **Source**는 `Deploy from a branch`, 브랜치는 `main`, 폴더는 `/ (root)`로 설정하고 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.
