# 스탠리파크에서 길을 잃은 날

그날 나는 언제 길을 잃었다고 느꼈을까?
스탠리파크에서 자전거를 타다 길을 잃은 하루를, 안내(사람·휴대폰)와 공간(눈앞의 길)의 관계로 따라가는 스크롤 작업.

## 파일

| 파일 | 내용 | 직접 수정 |
|---|---|---|
| `data.js` | 모든 문장, 장면 11개, 기록값, 스크롤 길이, 사진 파일 이름 | ★ 주로 여기만 |
| `photos/` | 그날 찍은 사진 | 사진 넣기 |
| `style.css` | 색, 서체, 레이아웃 (공간·사람·휴대폰 색은 맨 위 `:root`) | 색을 바꿀 때 |
| `main.js` | 화면 그리기, 스크롤 연동 | 보통은 필요 없음 |
| `index.html` | 뼈대 | 보통은 필요 없음 |
| `_v1/` | 이전 버전(지도 + 불안 수치) 보관 | — |

## 미리 보기

`index.html`을 더블클릭하면 브라우저에서 바로 열립니다. 서버가 필요 없습니다.

## 사진 넣기

1. `photos` 폴더에 사진을 넣습니다.
2. `data.js`에서 그 장면의 `files`에 파일 이름을 적습니다.
   예) `files: ["04-1.jpg", "04-2.jpg"]`
3. 파일이 아직 없으면 회색 상자에 파일 이름이 보입니다. 그 이름으로 저장해도 됩니다.

사진은 긴 변 1600px 정도로 줄여 넣으면 휴대폰에서도 빨리 열립니다.

## 확인 필요한 값 채우기

`data.js`에서 `"확인 필요"`를 찾아 실제 값으로 바꾸세요.

- 시각: `clock: "14:20"`
- 걸린 시간: `minutes: 7` 또는 `minutes: "약 7분"`
- 사진 장수: `photos: 12` (숫자로 넣으면 마지막 화면에 막대로 그려집니다)
- 배터리: `battery: 45`
- NODE 01·02에서 휴대폰을 봤는지: `phoneLooked: "보지 않음"`

`// 임시 문장` 표시가 있는 말(지나가던 여성, 커플의 말)은 실제 표현으로 바꿔 주세요.

## 스크롤 길이

각 장면의 `length`가 스크롤 길이입니다(1 = 화면 하나).
NODE 03은 체감 30분 ÷ 실제 7분 ≈ `4.3`으로 다른 장면보다 길게 잡았습니다.
걸린 시간 표시는 이 구간의 7/30 지점에서 7:00에 도달하고 멈춥니다. 바퀴는 그 뒤에도 계속 돕니다.

## GitHub Pages 배포

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다(`photos` 폴더 포함).
2. 저장소의 **Settings → Pages**로 갑니다.
3. **Source**는 `Deploy from a branch`, 브랜치는 `main`, 폴더는 `/ (root)`로 설정하고 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.

GitHub Pages는 파일 이름의 대소문자를 구분합니다. `01-1.JPG`와 `01-1.jpg`는 다른 파일입니다.
